# Uninstall

ForgeLoop installs plain files under `.claude/`.

To uninstall manually, remove the files copied from `skill/.claude/`:

```text
.claude/skills/implement-loop.md
.claude/skills/implement-loop/
.claude/agents/developer.md
.claude/agents/source-check.md
.claude/agents/tester.md
.claude/agents/reviewer-*.md
```

If you edited the templates after install, review before deleting.
